# Marca TáNoMar

A fonte aprovada da identidade é o kit em `docs/brand/tanomar-brand-kit`. A prancha `tanomar-brand-reference.png` continua como referência visual, mas não é mockup de tela.

Direção: oceano profundo, turquesa, coral e areia; moderna, leve e ligada ao mar, sem aparência de SaaS genérico, loja de pesca ou aplicativo de surf.

Âncoras oficiais:

- Oceano `#063B4C`
- Mar `#42C5BA`
- Ação `#FF7448`
- Areia `#F3E9D7`
- Espuma `#F8FBFA`
- Texto secundário `#59717A`

Os ativos executáveis ficam em `apps/web/public/brand` e `apps/web/public/icons`, copiados do kit raster. Não distorça, recolora, incline ou aplique sombra ao logo. Coral é cor de ação, não dominante.

Pendência: o kit é rasterizado. Para impressão ou ampliações extremas, é necessário obter ou redesenhar o vetor mestre aprovado — não fazer autotrace.
