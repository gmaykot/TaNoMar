## Paleta

- Oceano: `#063B4C`
- Mar: `#42C5BA`
- Ação: `#FF7448`
- Areia: `#F3E9D7`
- Espuma: `#F8FBFA`
- Texto secundário: `#59717A`

## Tipografia

- Interface e títulos: **Sora** (Google Fonts ou pacote local).
- Destaques emocionais manuscritos: **Caveat**. Não usar em textos funcionais, botões ou formulários.

## Regras rápidas

- Use o logo horizontal sobre fundos claros e com área de respiro mínima igual à altura do ponto laranja.
- Não distorça, recolora, incline ou aplique sombra ao logo.
- Coral é cor de ação/destaque, não cor dominante.
- Garanta contraste WCAG AA em textos e controles.
- Para produção definitiva e impressão, redesenhe/aprove o logo em vetor a partir do arquivo-fonte original. Esta prancha é rasterizada.
